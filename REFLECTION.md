# Week 1 reflection

Answer each question in 1–3 sentences, in your own words.

1. What is the difference between building a UI imperatively (plain DOM code) and declaratively (React)?

Answer: Building a UI imperatively requires the programmer to edit the UI in a sequential step whereas building the UI declaratively requires the programmer to explain and describe the UI based on the current data.

2. Why must a component name start with a capital letter?

Answer: React component names must start with a capital letter because React and JSX compilers can distinguish custom components from built-in HTML elements.

3. What does a fragment <>...</> do, and why not just use a <div>?

Answer: The React fragment allows the programmer to group multiple child  elements in JSX without adding an extra DOM node to thhe final HTML.

4. Name one benefit of splitting the UI into small components.

Answer: One benefit of splitting the UI into the small components is to provide convenient maintainability. It enables the programmer to update or fix one specific part of the interface in one place without breaking or disturbing another parts.
